締切トラッカー プライバシーポリシー

「締切トラッカー」（以下「本アプリ」）は、運営者個人（GitHub: bibi257）が、自分自身の締切管理のために作った個人用のアプリです。一般に公開しているサービスではなく、利用者は運営者本人のみです。

取り扱う情報

  • 締切のデータ: 運営者が本アプリに登録した締切（タイトル・日時・カテゴリ・メモなど）。Cloudflare 上のデータベースに保存します。
  • Google アカウントの権限: Gmail の「メールの送信」権限（https://www.googleapis.com/auth/gmail.send）のみを使います。メールの閲覧・読み取り・削除・連絡先へのアクセスは行いません。

利用目的

締切の一覧を、運営者自身のメールアドレス宛てに通知するためにだけ、Gmail の送信権限を使います。それ以外の目的には使いません。

第三者への提供

取得した情報を、第三者に提供・販売・共有することはありません。広告にも使いません。

Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

保管と削除

データは運営者のアカウントで管理する Cloudflare に保存します。運営者は、Google アカウントの「サードパーティによるアクセス」から、いつでも本アプリへの権限を取り消せます。データの削除は、運営者がデータベースから行います。

お問い合わせ

本ポリシーについては、GitHub の Issues からご連絡ください。

Privacy Policy (English summary)

"Deadline Tracker" is a personal app built and used only by its developer (GitHub: bibi257). It stores the developer's own deadline data in a private database on Cloudflare. It uses only the Gmail "send" permission (gmail.send) to send deadline notification emails to the developer's own address. It does not read, modify or delete any email, and does not share data with third parties.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account's third-party access settings. Contact: GitHub Issues.
