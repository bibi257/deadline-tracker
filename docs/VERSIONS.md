# 版番号（v3.1 など）

設定の「バージョン」に、「2026-10-31 08:00 v3.1」のように出る。日時は、画面のファイルを最後に変えたコミットの日時（JST）。
`v3.1` は、`index.html` の `<meta name="app-version" content="3.1">` に書く。`package.json` の `version`（`3.1.0`）と、先頭の2つ（major.minor）をそろえる（`test/unit/build.test.js` で確かめる）。
内容が同じかどうかを見分けるためのハッシュ（`[d21065ddfb]`）は、`build-stamp` の中に残してあり、表には出さない（版の文字にマウスを載せると「ビルド d21065ddfb」と出る）。

## 上げ方

| 上げるもの | 使う場面 | 例 |
|---|---|---|
| major（3 → 4） | 保存先・仕組み・画面の作りが大きく変わる変更 | GitHub → Cloudflare への移行、画面の全面的な作り直し |
| minor（3.1 → 3.2） | 目に見える機能・見た目の追加や変更 | 達成カレンダー、設定のメニュー化 |
| patch（3.1.0 → 3.1.1） | 不具合の修正・小さな直し | 表には出さない（`package.json` だけ上げる。上げなくてもよい） |

上げるときは、`index.html` の `app-version` と `package.json` の `version` を一緒に直し、この表に1行足す。
